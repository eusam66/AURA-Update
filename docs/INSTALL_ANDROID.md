# AURA Glass TV — Instalação manual na Android TV / Google TV

**Caminho principal e sem PC:** após uma Release pública autorizada, baixar o APK oficial na página [Releases](https://github.com/eusam66/AURA-Update/releases). Transferir para a TV por meio suportado (aplicativo de transferência, pendrive ou downloader compatível). Abrir no gerenciador de arquivos e permitir a instalação de fontes externas quando o Android solicitar.

**Para atualizar sem perder dados:**
- Usar APK oficial **com o mesmo pacote `com.auratv.player.engine3` e certificado original**.
- Instalar sobre a versão antiga. **Não desinstalar, não limpar dados e não restaurar de fábrica**.
- Versões mais antigas normalmente não podem substituir uma `versionCode` maior; não usar a Lite vc25 para rebaixar a Premium vc26/vc27.
- Se necessário, fazer backup local antes. Credenciais IPTV e histórico devem permanecer privados.
- O AURA Update interno será implementado na próxima etapa; este procedimento manual continua disponível.

O método opcional pelo PC (ADB/CMD/PowerShell) não é obrigatório e exige autorização/pareamento do dispositivo.
